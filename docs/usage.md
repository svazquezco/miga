# Usage

- **Mi masa madre**: see the latest feeding and use **Editar** to change the
  starter name or last feeding date. The starter card shows its last recorded
  activity or location. Use its storage actions when moving the starter to or
  from the fridge.
- **Ajustes**: manage the starter's storage and hydration.
- **La guía**: explore feeding recommendations and activity checks.
- **Asistente Miga**: choose a goal first, or start with a goal\n already selected from **Mi masa madre**. Check the starter before continuing.
  When preparing to bake, calculate the feeding and record it once completed to
  start a local countdown. Return to the assistant to see the same countdown.
  Check the starter’s growth before deciding whether it is ready.
  If you report gray or brown liquid without contamination, Miga guides you
  through an initial feeding and consecutive 1:1:1 feedings. Confirm two in a
  row that roughly double within four hours to resume the original goal.
- **Calculadora**: calculate ingredient amounts for a chosen total and ratio.
  In the results, **Masa activa** is selected by default and shows a reference
  time to peak for an active, mature starter at about 24 °C
  based on [a baker’s side-by-side observations](https://thatsourdoughgal.com/the-ultimate-guide-to-sourdough-starter-feeding-ratios/).
  The guide uses a separate [baking trial at about 26 °C](https://www.kingarthurbaking.com/blog/2025/03/13/sourdough-feeding-ratios).
  Select **Masa no activa** for a sluggish starter coming out of the fridge.
  The calculator shows which signs to look for during recovery in place of a
  peak estimate. In the assistant, recording this feeding starts a
  [12-hour check-in reminder](https://www.kingarthurbaking.com/blog/2021/09/02/did-i-kill-my-sourdough-starter).
  You can enter the fermentation temperature when recording the feeding.
- **Mi historial**: review feedings and observations.

Recommendations support one mature wheat starter at 100% hydration.
Contamination blocks feeding until you explicitly start a new culture.
Elapsed time alone never confirms readiness to bake.

Data stays in this browser. Settings lets you export a JSON copy; import and
sync are unavailable. Export before clearing browser data or resetting the
culture. A confirmed reset deletes the journal.

Install from Settings or the browser menu. On iOS, use Safari's **Share > Add to
Home Screen**. The production app works offline after a complete online visit.
There are no background notifications.
