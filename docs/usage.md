# Usage

- **Mi masa madre** shows the latest feeding and activity. Use **Editar** to change the name or feeding date. Open the floating Miga button to go to the assistant. It opens automatically the first time you scroll to the bottom of Home.
- **Ajustes** manages storage, hydration, export, and installation.
- **La guía** explains feeding and growth.
- **Asistente Miga** guides maintenance, baking, and recovery.
- **Calculadora** gives the amounts for a feeding. **Mi historial** lets you edit and delete feedings and observations.

For baking, record the feeding in the assistant to start a countdown. It reminds you to check growth. Recovery ends after two consecutive 1:1:1 feedings that roughly double within four hours. Contamination blocks feeding until you start a new culture. Recommendations cover mature wheat starter at 100% hydration.

Data is shared across tabs in the same browser. Export a JSON copy before resetting the culture or clearing browser data. If another tab saves while your changes are pending, export them before reloading.

Install from Settings or your browser menu. In iOS Safari, use **Share > Add to Home Screen**. After a complete online visit, the production app works offline. The app has no background notifications.
