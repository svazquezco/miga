# Usage

- **Mi cultivo y ajustes**: set the culture name, storage, temperature, and hydration.
- **La guía**: explore feeding recommendations and activity checks.
- **Asistente Miga**: answer questions and record observations or completed feedings.
- **Calculadora**: calculate ingredient amounts for a chosen total and ratio.
- **Mi historial**: review feedings and observations.

Recommendations support one mature wheat starter at 100% hydration.
Contamination blocks feeding until you explicitly start a new culture.
Elapsed time alone never confirms readiness to bake.

Data stays in this browser. Settings lets you export a JSON copy; import and
sync are unavailable. Export before clearing browser data or resetting the
culture. A confirmed reset deletes the journal.

Install from Settings or the browser menu. On iOS, use Safari's **Share > Add to
Home Screen**. The production app works offline after a complete online visit.
There are no background notifications.
