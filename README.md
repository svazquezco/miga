# Miga

A Spanish sourdough guide, assistant, calculator, and journal.
Built with React, TypeScript, and Vite. Data stays in your browser.

## Start

Requires Node.js 22.13+ and pnpm 11.5.3.

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

Open the URL printed by Vite. No account or environment variables are needed.
